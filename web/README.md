# web/ — Aplicación web (Python + FastAPI)

**Entrega 2.** Catálogo público, ficha de producto, carrito, checkout, página de seguimiento del
pedido (URL con token, muestra datos bancarios y sube el comprobante) y panel del voluntario
(bandeja de tareas del proceso). Habla con Flowable por REST (`docs/flowable-api.http`) y con
`ws-pedidos` para las operaciones de dominio.
